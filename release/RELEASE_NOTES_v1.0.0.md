用摄像头判断你是否还在电脑前：人离开就自动黑屏，回来立刻恢复。

## 这个版本做了什么

**检测**

- 基于 YuNet 人脸检测 + 5 点关键点几何分析，测量头部俯仰与偏转
- 在位 / 离开双状态机：进入离开用严格阈值、恢复用宽松阈值，正面信号需连续约 0.3 秒才生效
- 键鼠活动闸门：8 秒内有输入时拦截视觉误判，但人脸彻底消失超过 8 秒仍强制离开
- 关键点中位数滤波，抑制单帧抖动造成的误判

**黑屏**

- 全屏纯黑遮罩，覆盖所有显示器，带看门狗 —— 被播放器、通知横幅等置顶窗口盖住后会自动重新置顶
- 黑屏期间**按任意键 / 移动鼠标 / 点击鼠标**即可解除，直接读系统全局键鼠状态，不依赖窗口焦点（输入法候选框、游戏、远程桌面抢占焦点时同样有效）
- 可选「解除后 N 秒仍未回来则重新黑屏」，防止起身时误碰一下鼠标让整段离开失去保护

**定时计划**

- 按星期 + 时间段自动启停，程序常驻托盘不用退出
- 支持跨午夜（例如 22:00–06:00 算到第二天）
- 只在跨越时间边界时切换一次，时段外手动启用的状态不会被下一轮轮询推翻

**其他**

- Qt 设置窗口四个页面：触发动作 / 判定规则 / 定时计划 / 实时预览
- 系统托盘常驻，支持开机自启、暂停/恢复
- 设置窗口可实时看到检测画面、角度读数与判定原因

## 下载与安装

下载 `EyeGuard-v1.0.0-win64.zip`，解压到任意目录（建议固定位置，别放桌面临时文件夹），运行里面的 `EyeGuard\EyeGuard.exe` 即可。

**不需要安装 Python**，所有依赖已打包。首次启动会在程序目录生成 `config.json`，并自动弹出设置窗口。

## 系统要求

- Windows 10 / 11 64 位
- 摄像头（笔记本内置即可）

## 说明

- 压缩包内**不含 `config.json`**，首次运行使用默认参数并提示校准；升级时直接覆盖程序文件、保留原来的 `config.json` 即可继承设置
- 包内附 `使用说明.md`，参数含义和误判排查方法都写在里面
- 程序为无签名 exe，SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可
