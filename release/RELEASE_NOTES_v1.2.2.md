用摄像头判断你是否还在电脑前：人离开就自动黑屏，回来立刻恢复。

这一版最大的变化是**黑屏时屏幕上多了个工资板** —— 反正黑着也是浪费，干脆把「今天赚了多少、还剩多久下班」打上去。

## 相比 v1.0.0 新增了什么

**上班鼓励器（新）**

- 黑屏正中显示：今日已赚（主数字）、时薪、每分钟赚多少、今日进度条、距离下班的倒计时
- 金额按秒连续折算，不做整点跳变；工资板每 90ms 刷新一次，配上厘位小数，数字像水表一样一直往上爬
- 所有费率**精确到厘**（小数点后 3 位）：`10000 ÷ 21.75 = ¥459.770`，`÷ 6.5 小时 = ¥70.734/时`
  先把费率定格再往后乘，界面上写多少，后面就按多少算，不会出现尾数对不上
- **午休可以挖掉**：写成 `08:30–11:30 + 14:00–17:30`，午休那 2.5 小时不产生收入 ——
  金额和进度条会停住，文案变成「午休中 · 距下班 X」，下午开工再接着走
- 支持跨夜班次（22:00–06:00 这种，周二凌晨算的是「周一那班」）
- 非工作日、还没开工、已经下班都有对应文案，不会甩给你一个假数字
- 设置窗口新增「上班鼓励器」页，上班时间默认继承「定时计划」里的时段

**其他**

- 设置窗口现在五个页面：触发动作 / 判定规则 / 定时计划 / 上班鼓励器 / 实时预览
- 黑屏大金额与费率全部到厘，消掉了原来「显示 459.77、实际按 459.7701 算」的偏差

## v1.0.0 已有的功能（一并说明）

**检测**

- YuNet 人脸检测 + 5 点关键点几何分析，测量头部俯仰与偏转
- 在位 / 离开双状态机：进入离开用严格阈值、恢复用宽松阈值，正面信号需连续约 0.3 秒才生效
- 键鼠活动闸门：8 秒内有输入时拦截视觉误判，但人脸彻底消失超过 8 秒仍强制离开

**黑屏**

- 全屏纯黑遮罩，覆盖所有显示器，带有看门狗 —— 被播放器、通知横幅盖住后会自动重新置顶
- 黑屏期间**按任意键 / 移动鼠标 / 点击鼠标**即可解除，直接读系统全局键鼠状态，不依赖窗口焦点

**定时计划**

- 按星期 + 时间段自动启停，支持跨午夜，只在跨越边界时切换

## 下载与安装

下载 `EyeGuard-v1.2.2-win64.zip`，解压到任意目录（建议固定位置，别放桌面临时文件夹），运行里面的 `EyeGuard\EyeGuard.exe`。

**不需要安装 Python**，所有依赖已打包。首次启动会在程序目录生成 `config.json`，并自动弹出设置窗口。

从 v1.0.0 升级：直接解压覆盖，保留原来的 `config.json` 即可继承设置（新增的配置项会自动补上默认值，并在「上班鼓励器」页把上班时间继承自定时计划）。

## 系统要求

- Windows 10 / 11 64 位
- 摄像头（笔记本内置即可）

- 压缩包内**不含 `config.json`**：里面有校准基准和个人薪资参数，首次运行请从默认值开始并走一次校准
- 包内附 `使用说明.md`，参数含义、换算口径和误判排查方法都写在里面
- 程序为无签名 exe，SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可
